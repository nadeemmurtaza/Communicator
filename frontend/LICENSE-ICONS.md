# Icon artwork

## Duotone UI icons — Solar

`src/components/icons/duotone-icons.ts` contains path data from the **Solar** icon
set, generated by `scripts/generate-duotone-icons.mjs`.

- **Author:** 480 Design — <https://www.figma.com/community/file/1166831539721848736>
- **Licence:** CC-BY-4.0 — <https://creativecommons.org/licenses/by/4.0/>
- **Obtained from:** npm package `@iconify-json/solar`, pinned at `1.2.13`, as
  published through [Iconify](https://iconify.design). The licence name, author
  and URLs above are copied from that package's own `info.json`, not from a
  web page.

This product includes icons from the Solar icon set by 480 Design, used under
CC-BY-4.0. Attribution is required by that licence; this file is it.

Only the 126 icons the app imports and 4 channel glyphs are written into source.
The rest of the collection (8,706 icons) is not redistributed — it never enters
the repository or the bundle. Regenerate with:

```
cd frontend && npm run icons:generate
```

The generator reads the installed package, refuses to write when a name has no
mapping or an artwork cannot be parsed, and checks that every mapped name is
exported. `@iconify-json/solar` is a devDependency: it is needed to regenerate
the data, not to build or run the app.

## Channel logos

`src/components/icons/brand-marks.ts` holds the published logo paths for WhatsApp,
Instagram, Facebook, Telegram, TikTok and LINE. Those marks are not part of Solar
and are not duotone: they are the trademark shapes as each service publishes
them, shown only to identify the channel a user is connecting. They are kept in
their official single-tone form because fading half of a mark to 50% opacity
distorts it. Each remains the property of its owner; nothing here grants rights
to them.

## Why not IcoFont

IcoFont (<https://icofont.com>) was the first choice for this, and it did not
work out as a source:

- The npm package `icofont` (v1.0.0, CC-BY-4.0) ships a **webfont** plus CSS. A
  font glyph has one colour slot, so it cannot render duotone at all — the
  two-tone effect needs two SVG layers per icon.
- `react-icofont`, `@icon/icofont` and `react-icofont-wrapper` wrap that same
  font, so they inherit the same limit.
- icofont.com advertises free SVG downloads including duotone icons, but no bulk
  archive or CDN URL is exposed on the pages checked, `https://icofont.com/download`
  returns 404, and there is no repository publishing the SVG set. Its license
  page describes some duotone packs as premium. Getting duotone IcoFont artwork
  would mean saving each icon by hand from the site and resolving that licence
  question first.

Switching to IcoFont later, if its duotone SVGs become obtainable, is a data
change only: replace the bodies in `duotone-icons.ts` and every page keeps
working, because all icons enter the app through `src/components/icons`.
